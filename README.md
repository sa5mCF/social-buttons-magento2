# Core SocialButtons

This is the Core SocialButtons module for Magento 2.

## Requirement
- Magento 2.x

## Installation
1. Go to your Magento 2 root directory.
2. Run `php bin/magento module:enable Core_SocialButtons`
3. Run `php bin/magento setup:upgrade`
4. Run `php bin/magento setup:static-content:deploy`
5. Run `php bin/magento cache:clean`

## Description
This module provides social button features.
